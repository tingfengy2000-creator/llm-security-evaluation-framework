2. Distribute Phase1 V2 package + schema + respective prompt. Verify identical candidate/order and semantically equivalent instructions. Lock each unmodified raw return separately with source bytes, SHA256, timestamp, 24/24 exact ID/order/schema/enum validation and an [attestation](PAPER1_FORMAL_D1_FRESH_REVIEW_RUN_ATTESTATION_SCHEMA_V1.json). 4. Release the same frozen Phase2 V3 package, schema and V4.1 clarification to each reviewer **in their own Phase1 session**, with only their platform-specific prompt boundary differing. Lock each unmodified Phase2 raw with SHA256, 24/24 validation and a new run-level attestation.

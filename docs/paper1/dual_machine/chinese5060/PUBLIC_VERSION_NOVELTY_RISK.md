## 高风险主张与反证

1. **“首次识别时效污染”风险极高。** 真实反转、历史版本以及有效时间对照均已有原始证据。将日期优先和有效区间控制做成可运行的简单基线，同一条真实旧证据在适用查询中误删应记为 HN 失败。
2. **“来源收据就是新算法”风险极高。** 给联合方法独占的可信元数据足以制造信息优势。用同一份收据、时点和预算测试简单规则与联合门控，并做去范围消融。若简单规则达到同样的安全与效用，保留基准贡献，撤回联合方法主张。
3. **“同值或独立域名即可抵抗多数”风险极高。** 同源转载、改写和伪造网址可形成虚假票数。来源谱系去重并以真签发者失陷作为单独压力条件。分别检查 3/5、4/5、5/5。出现错锚、错误放回或同范围误判时完整保留负结果。
4. **“中文即可构成创新”依据不足。** 可以检验中文版本化正文的薄弱点，如时效过渡、适用对象、数字与行政责任变更是否使冻结 RD‑zh 更常丢失合法证据。须有独立选材、可核引用和事前定义的不同条件，而后才能审议贡献边界。
5. **“过滤收益可代表答案正确率”依据不足。** 本轮无任何方法结果；下一批最小试验也仅拟做候选过滤。Qwen、生成和正式 ASR 各自需要新的授权和匹配协议。

当前唯一可预注册的机制假设是，在**共同可见且可验证的来源信息**下，来源绑定、适用区间和 scope 联合条件能比同证据的简单规则少删正常片段，且不增加 Poison 保留和 HN 误删。失败时转为中文版本敏感污染基准与 RD 中文迁移失效分析。该假设尚未测试，同行工作覆盖范围的判断限于本次核对的原始论文和制品。

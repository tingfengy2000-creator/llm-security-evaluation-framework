## W1–W4 机制归因

- **W1 CONFIRMED（限固定单跳 TopK5）；普遍必删 REFUTED。** Stage 1 把非空 TopK5 聚成两个非空簇，TF-IDF 多数计数 ≤2 时取小簇，否则取大簇，N_adv 因此落在 1–4。实测 B2 删除 1、2、3、4 段的世界分别为 6、18、9、3 个。库允许空检索直接返回，也允许在 N_adv≤0 时跳过 Stage 2。v0.2.0 按片段参与高相似对的加权分数选删除索引，平分按原索引，v0.1.1 的尾部截断不适用。 [Stage 1](https://github.com/SecAI-Lab/RAGDefender/blob/ba2a17efba165d45409114df2d70b030ade1e1b8/ragdefender/grouping/clustering.py) · [防御入口](https://github.com/SecAI-Lab/RAGDefender/blob/ba2a17efba165d45409114df2d70b030ade1e1b8/ragdefender/defender.py) · [Stage 2](https://github.com/SecAI-Lab/RAGDefender/blob/ba2a17efba165d45409114df2d70b030ade1e1b8/ragdefender/identification/topk.py)
- **W2 CONFIRMED（决策信号）。** 固定轨道根据词面重复和向量相似度估计污染数量、选择删除片段，不比较事实值、适用范围或生效版本。该机制允许删掉正常证据，S0 观察到上述误删。它对最终回答错误或拒答的单独因果贡献仍未确定。 [词项和投票](https://github.com/SecAI-Lab/RAGDefender/blob/ba2a17efba165d45409114df2d70b030ade1e1b8/ragdefender/grouping/clustering.py) · [相似对频率评分](https://github.com/SecAI-Lab/RAGDefender/blob/ba2a17efba165d45409114df2d70b030ade1e1b8/ragdefender/identification/topk.py)
- **W3 UNRESOLVED（多数污染的实际失效）。** 当前每个世界只有一个构造候选，无法实测 3/5、4/5、5/5 污染。原论文 VI-E 已讨论自适应相似度规避和改写，VII 讨论聚团假设与边界，附录 C 分析低相似或伪装正常引起的漏检。“原作者未讨论此类问题”不成立。 [作者论文](https://doi.org/10.1109/ACSAC67867.2025.00093)
- **W4 CONFIRMED（中文词项切分未迁移）。** 两臂均用 scikit-learn 英文停用词和默认双字以上词元规则，按权重取前五词，再按原文子串计票。36 个世界共 180 个 top-term 位置，171 个含汉字，142 个含至少四个连续汉字。12/36 个世界触发取大簇。换成多语种 embedding 不改变这条词面路径，本轮没有单独测量分词对误删的因果影响。 [官方词面逻辑](https://github.com/SecAI-Lab/RAGDefender/blob/ba2a17efba165d45409114df2d70b030ade1e1b8/ragdefender/grouping/clustering.py)

B1/B2 均使用官方公开库 v0.2.0 的同一源码提交 `ba2a17efba165d45409114df2d70b030ade1e1b8`，CPU、单跳、`p=2,m=5`。B1 注入库默认预设对应的 all-MiniLM-L6-v2，B2 只替换为 paraphrase-multilingual-MiniLM-L12-v2。模型 revision 见证据索引。论文实现用 Stella，两臂都未加载 Stella，也未复现论文实验。 [官方 embedding 预设](https://github.com/SecAI-Lab/RAGDefender/blob/ba2a17efba165d45409114df2d70b030ade1e1b8/ragdefender/embedders.py)

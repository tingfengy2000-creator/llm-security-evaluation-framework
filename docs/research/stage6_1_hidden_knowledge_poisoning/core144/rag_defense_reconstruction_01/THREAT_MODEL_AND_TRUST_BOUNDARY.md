# 威胁模型、信任边界与标签隔离

2026-11-04 JST；协议候选，场景未生成。

攻击者只能控制预设低信任检索文档的正文及其自述来源/时间声明、在冻结预算内的注入位置/数量；不能改 query、system prompt、独立官方证据快照、评价裁决、真实来源验证状态或其他反事实世界。当前是自然事实变异研究，不能把显式指令注入结果替代它。

区分四个面：攻击者可控载荷；独立验证的官方证据；普通未核验文档；固定查询与系统指令。攻击者可控身份与 Poison/attack_goal 仅评价器可见。模型 trust_boundary 仅有 INDEPENDENT_TRUSTED / UNVERIFIED，必须基于实际来源验证，不基于标签；同一未核验边界含正常与错误材料。自述“官方”不能提升信任。

source_role、publication_time、effective_time、version 的公开值需要可追溯来源；文内宣称与外部验证记录需分清。来源权威不能替代适用范围，发布日期不能替代生效日期，多源转载不能算多份独立支持。缺证、未知和冲突均不自动等于恶意。

模型可见数据禁止 label/poisoned/attack_id/attack_goal/expected_answer/ground_truth/oracle/私有 S/组/家族以及嵌套、序列化注释泄漏；当前 contracts.py 先递归扫描再验证 allowlist。evaluation_preparation.py 只在 control-plane/evaluator 读取签署标签完成预结果抽样。ID/文件路径/正文暗示、隐式映射与人工判断泄漏仍需单独审查，单元测试不证明完全无泄漏。

运行数据无三元组兄弟映射；评价器先核实互斥场景再输出公共包。GroundTruthVault/评价器保存答案与攻击目标，过滤器和生成器均不可读。实验预测先封存，再按预定评分解封评价；不得事后换题、改合法历史标签或按模型输出补答案。

公平访问：B0–B5 都获得同一公共证据预算和经验证元数据，不额外给 B4 可信文档或正确答案。B0 保留所有可用上下文，包括共同可信证据。B2 原 API 只使用段落几何/词频，它不消费额外 metadata 是算法自身能力边界；不能借此给其他方法加一份隐形 Oracle。生成阶段共同规则、顺序与预算不变。

私有正文、标签、逐样本 raw、密钥、完整环境与模型不入 Git；仅脱敏汇总、源码、测试、论文链接和哈希进入版本控制。原 D1/D2/D3/Human/GT/旧 L0/E1–E4 的字节与结论保留。私有归档只含明确 allowlist，不递归打包整个 env/cache/upstream 或旧签署标签库。

# Runner 安全、隐私与资源审计

- CLI 由 `python -I -S -B` 启动。运行前安装不可移除的 CPython 审计钩子，拒绝 socket 创建、DNS 解析、子进程及动态 SDK/本地桥接入口。隔离子进程测试触发真实 Python socket 和 DNS 操作，均在调用操作系统前被拒绝。此控制的范围是专用 Runner 进程，系统网络配置维持原状态。
- 运行时读取白名单仅包括固定 proposal、角色盲生成计划、P2/PAIR01 输出封存、限定源码以及显式哈希指定的受控预算文件。以拒绝合成评价文件读取验证白名单。请求只包含固定 system、原 query 和原排名的片段。真实参考 JSON 留评价侧。
- `FakeTransport` 为唯一可实例化并执行的发送路径，要求精确类型、未使用实例及零重试。运行模块仅依赖 Python 标准库与仓库本地纯函数。live 构造失败，CLI 即使提供 approval 和环境开关也退出 2。
- 输出须为指定受控 runs 目录下的新子目录，拒绝重定向路径和 C 盘。启动及逐格检查 D/E 20 GiB 余量。缓存环境变量与 `tempfile.tempdir` 指向同一受控输出下的 `local_scratch`。此次 D 盘演练后可用 357,409,742,848 字节，保留要求 21,474,836,480 字节。受控资源写入全部在 D，测试覆盖合成 C 写入拒绝。
- 请求意图和结果均写入持久日志，原始模拟响应独立保存并以 SHA 绑定；统一封存覆盖结果、计划索引、日志、原始响应和运行清单。输出以独占写入创建，既有运行不能覆写。硬断电或磁盘故障时以已落盘日志和计划索引作为恢复证据，人工核对后另决，不自动续跑。
- 响应审计保留状态、模拟请求 ID、用量字段及原始响应 SHA。客户端未读取凭证，日志无授权头、Cookie 或真实私有预测。私有归档使用 Git 忽略目录，公开 QA 只列哈希、汇总、脱敏命令及退出码。
- 真实评价释放仍需独立审批和真实全量结果封存，模拟封存会被明确拒绝。此次实际模型请求、付费 API 和评价调用均为 0。

详细检查和私有归档身份见 [工程 QA](DRY_RUN_AND_QA.json)。

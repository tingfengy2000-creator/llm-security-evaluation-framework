## 数据与人工裁决

- 先对 Owner28 的已封存 32 个问题、160 个 TopK 槽和四组事实准备两人独立盲审。两人各自记录版本、事件时点、范围和原文出处，第三人裁决分歧。隐藏既有 Agent 标签、攻击目标提示和过滤臂。保留原两份判断、裁决记录与哈希，分别汇报覆盖、分歧和未裁决。只有实际签署且链路完整的记录计入 Human Gold。已有候选结果沿用原评分版本，若未来批准以人审另计，须用独立版本发布。
- 新批目标至少 24 个新事实单位、至少 6 条未见谱系。按谱系隔离开发与确认集，排除已暴露的开发、评价和预检谱系及同源改写。确定语料合法可用、可引用和可复核后，按预先登记的次序采样。采样规模须结合谱系簇数、预期失访和预期差异做功效或精度评估。24/6 是草案设计目标，未批准，也不足以单独保证推断精度。
- 每一文档记录签发机构、原始 URI、精确版本和原文定位、公开/施行/废止或过渡日期、地域与对象、取样时间、许可范围和内容 SHA。自然原文和代理释义分别标记和报告。外传资格、可公开范围和可保留字节须分别核对。未知时保留 UNKNOWN，候选排除或改为已获批准的代理批次须在冻结前决定。
- 新事实保留干净、合法旧版、真实他范围、错误范围替换、单段污染、近重复多数、改写多数、伪造新版等预先登记条件。按实际 TopK 污染密度分层，并对 5/5 设置单列最低覆盖目标，实际未达到则记 NOT_COVERED。候选标注区分合法性、对当前问题的适用性和应保留的辅助证据，防止把相关性判断当作真假裁决。

## 同 TopK 的最小强基线

每个世界预先冻结问题、事件时点、同一有序 TopK5、片段和文档标识、来源条件与上下文预算。四个核心臂使用同一输入版本和同一生成器。

| 臂 | 拟冻结定义 |
| --- | --- |
| NONE | 保留原 TopK 秩，提供检索与生成基准。 |
| RD_B2 | 现有上游和中文缓存迁移参数。 |
| RD_ZH | 仅 Stage 1 中文字符 bigram 与停用词差异。 |
| TEMPORAL_SCOPE | 规范化查询事件日期，解析候选公开字段或可审计的文本日期，使用显式生效及废止区间和范围条件判断适用性。只在版本与范围均可绑定且明确不适用时过滤。缺失、冲突或无法规范化时保留并记 UNKNOWN。 |

TEMPORAL_SCOPE 先在独立开发集冻结抽取规则、日期格式、半开区间、生效与发布日期优先级、过渡条款、范围词表、证据归属和 UNKNOWN 路径。用未接触确认集的测试夹具分别验日期、范围和过渡条款正反例。在确认集报告可解析覆盖、决策覆盖、未知回退、与 NONE 的掩码差异及漏删/误删。若规则对所有确认世界仍无有效决定，记为失效对照并公开，不通过事后修改获得新分数。

主比较使用共同可见的文本与查询。若加入可部署的签发元数据，另开共同可见的来源条件，所有同层对照共享相同字段与预算。字段由与标签隔离的采集/解析流程生成，版本、范围或规范值不得从造数卡、Gold 或已有结果写入。来源侧成本计入端到端报告。

## 回答层与统计

- 在人审冻结后封存同一查询、证据预算、截断方式、提示模板、生成模型与 revision、tokenizer、解码参数、最大输出和随机种子。首选已经验明许可且单独获准的本地中文生成模型。模型身份和预算在正式批准前待填。各臂按照固定顺序使用原秩证据，记录空上下文和输入截断。没有合法模型或明确资源门时停止于候选层。
- 先登记攻击目标、允许答案变体、查询可回答性、来源引用要求和时点冲突裁决。盲审者看不到臂名和攻击设计。预设异常输出、请求失败、不可回答与主动拒答的分类，全部计数公开。只有预先冻结为可回答的问题才进入准确率分母，错误拒答保留在该分母内。
- 回答层主要比较 TEMPORAL_SCOPE 与 RD_ZH。报告 targeted ASR，即在预先定义了攻击目标的攻击条件问题中，输出命中目标错误答案的比例。主分母包括同批未召回污染的问题，条件于已召回污染的 ASR 单列。准确率用满足事实、时点、范围和完整性标准的回答除以可回答问题数。拒答率按全部请求报告，并拆分可回答与不可回答组。另记不受证据支持回答、误引、时间冲突和未测项目。
- 候选级报告投放、召回、漏召回、P 保留与检测召回、C/HN 误删、背景删除，以及过滤后有效上下文覆盖。段删除或污染漏召回均不直接代入 ASR。空上下文和 5/5 无合适证据的条件报告合理拒答与错误作答，区别于可回答样本。
- 主表给出臂间配对的百分点差和计数。分析以事实组配对，推断单位以谱系簇处理。先报告逐组、逐谱系和缺失分母，微平均作为描述性补充。有效簇不足时仅报告描述统计。若簇数和功效审核通过，预先锁定谱系级配对区间及多重比较方案，保留所有负例。
- 同时记录总 input/output tokens、每世界和每臂的实际处理成本、失败次数及中位/P95 延迟。编码、解析、过滤和生成各阶段单列，另给总成本。共享缓存的实际摊销与各臂完整逻辑成本分别列明。已授权外部模型才可使用，须先核对许可、预估与硬预算。当前草案不调用 API，费用为 0。

## 冻结与停发门

最短论文质量门依次是逐源权限与出处核验，两位独立人审加一位裁决，新增独立谱系与分层覆盖，强时效基线在冻结前通过语义和覆盖预检，最终生成模型、查询 Gold 和评测协议获准，报告真实 ASR、准确率、拒答、时延和成本，再说明原作者复现差异。每一步保留原始版本与哈希。

任何来源或权限不明、标签泄漏、谱系交叉、分母与冻结 SHA 不符、模型或预算门未闭合，均停止相应阶段。实际掩码或回答一经封存，阈值、样本和评价规则保持该批冻结版本。待 Owner 签署事实组规模、基线版本、模型与预算、主要比较和统计方法后，另发执行合同。

# 项目长期协作上下文

本目录是 CodeGuarder 项目的长期协作入口，用于在跨会话、跨阶段和多人协作时保持目标、进度与实验治理一致。

建议按以下顺序阅读：

1. `01_priority_instructions.md`：用户最高优先级目标与 Teaching Mode。
2. `02_stage_progress.md`：Stage 1–7 的真实进度、成果和结论边界。
3. `03_artifact_management.md`：代码、数据、日志、报告和 Git 管理规则。
4. `04_collaboration_context.md`：后续实施必须保留的技术上下文与执行清单。
5. `05_project_roadmap.md`：Stage 1–7 的后续优先级、里程碑和完成标准。

状态词统一含义：

- `已完成`：代码、运行证据与交付文档已经存在。
- `已完成（Mock）`：框架已验证，但结果来自确定性 Mock，不代表真实模型结论。
- `开发中`：位于功能分支，尚未形成完整阶段交付。
- `规划中`：只有方向或接口预留，尚未实施。

本目录是导航和协作依据，不替代原始实验记录。发生冲突时，以原始 JSON/JSONL、运行日志、Git 历史和阶段报告中的证据为准。

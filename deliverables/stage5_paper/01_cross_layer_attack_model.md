# 跨层攻击模型

## 本阶段目标

明确 A1 数据污染表现、A2 后门 trigger 表现、A3 检索上下文污染、A4 运行时提示操纵、
A5 机密外泄和 A6 工具动作注入。

## 为什么这样设计

不同层的修复责任不同：训练层需要供应链治理，检索层需要来源与上下文隔离，运行时需要
Guard、权限和输出审计。

## 和上一阶段的关系

原六类攻击主要是运行时分类；A1-A6 将攻击来源和观察位置显式写入 schema。

## 当前结论边界

框架只观察运行时表现，不训练模型、不实现 RAG、不连接 Agent 工具。

## 面试时怎么讲

威胁层是原因维度，Attack ID 是实验维度，二者都进入 AttemptRecord。

## 不能夸大的地方

不能把 A1/A2 描述成真实训练供应链攻击实验。

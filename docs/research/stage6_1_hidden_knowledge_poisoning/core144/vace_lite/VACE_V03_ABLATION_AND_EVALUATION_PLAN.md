## 1. 先问可证伪的问题

Q1：语义I证明能否避开A0对合法同cue文本的误报，同时不漏掉无cue内部冲突？
Q2：相同可用证据与判决语义下，自适应能否降低成本，而不因错误早退/漏补证损害Recall/HN？
Q3：受限补证的改进有多少来自更多证据，而非六槽位约束或调度？
Q4：版本与机关角色约束是否真正减少合法历史/例外/机关角色HN误报？
Q5：充分性与弃权是否可靠，还是通过不处理困难样本制造低FPR？

## 4. 主要检测指标与真实分母

锁定预测及路由trace后，Evaluator才关联Role/GT/HKP/S。S仅用于事后分层，不是Runtime动作选择。
Poison Recall_s = CONTRADICT且真实Poison的该层数量 / 该层全部有效Poison。
Overall Recall同理；弃权/解析失败不计TP，但须与SUPPORT误放分别列出，不能偷偷删正例分母。
Clean-FPR、HN-FPR分别用全部有效Clean/HN作分母；INSUFFICIENT不是负类，另报这些样本的弃权率。
Precision以实际标记CONTRADICT的全部候选为分母；无标记则NA，不填0。

主候选操作点：HN-FPR≤10%、≤20%，以及全体/按角色复核预算β（尚待Owner冻结）。
要求**联合可行**：满足FPR与复核预算，而非把全部HN弃权换低FPR；无可行策略则报NOT_FEASIBLE。
D1当前40个HN中一例为2.5个百分点，≤10%最多4个、≤20%最多8个，只是分辨率解释，不能在评测标签上选阈值。
三态系统若暂无合法标量评分，只报告固定政策操作点，不编造AUROC/AUPRC或“最优Recall@FPR”。
未来有冻结可排序分数才计算AUROC/AUPRC；INSUFFICIENT不可随意赋0/0.5/1凑曲线。
涉及弃权的主报告保留全体结果和未决数量，选择性指标以已裁决子集另报并注明覆盖率。

阈值/有限政策选择只在指定train/dev进行；若D1开发阶段也要无内层泄漏的家族OOF操作点，
则外层留一家族、内层train家族选择，锁后应用到外层，不能用pooled外层标签挑阈值再报OOF。
该嵌套设计也只是D1_DEV诊断，不能重新变成untouched test；固定逻辑充分性条件不能为追分随意放宽。

## 5. 三元组、路由、证据与成本指标

| 维度 | 必报内容 |
| --- | --- |
| 组内判别 | P>C、P>HN win/tie/loss；全组严格成功=Poison标CONTRADICT且两负例SUPPORT / 全部组数 |
| 未决三元组 | 任一INSUFFICIENT组数单列，不算win；已裁决子集排序另报覆盖，不将弃权当0风险 |
| 路由 | I早退率、I早退证书错误率、外证到达率、T/P/J触发率、漏触发/多触发与无进展率 |
| 充分性 | 相对独立证书参考的假充分/假不足；义务/slot绑定、source/版本支持率，非只看文本相似 |
| 证据 | 首轮/终轮必要前提覆盖、query/UID/span/hash、第二前提未召回 vs 已在但未使用 |
| 弃权 | 总量及C/P/H、S/HKP/历史HN分布；原因码；进入人工队列数、未处理Poison及预算溢出 |
| 成本 | 每样本/分支真实检索、Registry、解析和模型调用；输入/输出tokens、正文份数/字节、mean/median/p95时延 |
| 工程公平 | 同硬件与并发、冷/热缓存、超时/失败/重试成本、离线准备与在线消费分开，不仅统计模型调用 |

若暂无标量风险，前述组内主指标只评估明确三态成功，不宣称已测连续risk margin。
分支成本按实际到达条件计，再按全体平均，不能只报告容易I早退样本的成本。
节省成本是待测假设：六槽位提取/Registry/复查可能抵消少调用收益。

## 6. 路由与充分性的独立参考

未来可申请分离的slot/span/证明义务参考及证书审查，先Candidate-only、再Evidence绑定，双人独立/Owner处理分歧。
这不是修改现有Human GT，也不要求强制“真实S1必须I早退”或“真实S3必须两次检索”。
一个有能力限制的系统可以对S1弃权，单份新证据可能足以联合支持命题；路由正确性按可用输入/政策义务审计，不按S值硬匹配。
独立参考用于Evaluator，不向Router开放；AI生成的理由不能自动当证明gold。
额外预算回放可审计早停是否漏掉反证，但回放也不是真值，不能倒灌改变已锁路由。

## 7. 必须预注册的边界/不变性测试

仅登记虚构测试要求，本轮不执行检测：
带“既…也/同一”但合法；无cue的互斥断言；不同时间/条件的相反规定；
“至少5天/10天”相容；采用机关与公布机关不同；双机关无排他共同公布；引述错误观点；
未收录版本；一文档含两端充分事实；两文档仍缺scope；明确权威主张未证不得早SUPPORT；
SHA/UID错误；证据顺序变化/重复文档；超过预算；空查询、截断或非法JSON；opaque ID替换。

S3必要证据移除只在已核最小充分集上定义；存在替代充分证据时，不强求转INSUFFICIENT。
旧版替换、新无关证据和顺序扰动的期望先定；不为使消融“成功”而修改既有Candidate/Evidence。

支持价值：同池同组件降低成本且Recall/HN不恶化；或同预算降低HN误报且保持Recall，收益超出S1 cue。
反证/收缩：I早退HN误报不可接受；差距仅来自更多证据/更大模型；更高弃权造成表面低FPR；
固定同池/同组件后调度收益消失；强L0/NA同样好或更好；主要gap无法由冻结库解决。

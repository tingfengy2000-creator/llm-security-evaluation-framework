# 大模型安全项目面试复习中心

该目录集中整理项目学习、实验过程、结果边界和面试话术。原始报告仍保留在
`deliverables/`，`source_copies/` 保存关键中文文档副本，便于面试前离线查看。

建议顺序：

1. 先读 `../docs/project_context/01_priority_instructions.md`，确认项目目标和结论纪律。
2. 再读 `../docs/project_context/02_stage_progress.md`，建立 Stage 1–7 全局视图。
3. 阅读 `01_知识地图.md`。
4. 阅读 `02_项目完整实现过程.md`。
5. 阅读 `05_实验结果与结论边界.md`。
6. 练习 `03_面试话术.md` 和 `04_高频追问.md`。
7. 使用 `06_复现命令.md` 做最后复跑检查。

项目后续路线见 `../docs/project_context/05_project_roadmap.md`。

# 面试话术

## 30 秒

我完成了一个从 garak 基础扫描到真实模型 Guard 消融的安全评测项目。系统使用统一
OpenAI-compatible Proxy，对 P/I/O/F 四种防护配置运行 A1-A6 跨层攻击矩阵，并通过
T1-T9、ASR、DMR、GBR、误拦和延迟指标解释失败原因。

## 1 分钟

项目先用 mock 隔离 API 和模型因素，再接入 Groq。Stage 4.1 证明 Output Guard 会在
模型生成并记录 raw hash 后拦截。Stage 5 Paper 不使用 garak scheduler，而由 Dataset
Runner 固定样本顺序；官方 garak detector 与自定义 pattern oracle 分开记录来源。
canonical log 排除时间与延迟，使 mock 重跑字节一致；真实模型波动放入 measurement。

## 不能夸大

A1/A2 只是训练层风险的运行时表现模拟；smoke 指标不是生产防护率；PASS 只表示指定
detector 未命中，不等于模型绝对安全。

## 现在不能做的事

尚未指定审阅者，也没有任何一份正式答卷。在授权真人签署之前，不得把本包、代理标签或暂定评分写成 Human Gold。

审阅者不得提前看到代理的 P/C/H/B 标签、模型保留或删除结果、臂的名称和已经算出的评分。分发时不要附带评分报告、预测投影或私有标签。两名初审人互相看不到对方的答卷。

## 审阅者看到什么

每个问题给出：法规名称、问句、对象、查询时点、条件和所问谓词，以及该谱系较早文本和较晚文本的公开网址、条款定位和施行日期。较早或较晚只表示时间先后，不表示哪一版是本题答案。

每个问题附带 5 段实际检索到的自写释义，共 160 段。顺序已经打乱，页面上的序号不是检索名次。160 段都标记为 `SOURCE_UNVERIFIED`：事实谱系的官方页面已经核过，但这些段落本身没有逐句核对成官文原句。找不到原句就保持这个标记，不得推测。

## 每段要填的栏

| 栏 | 取值 |
| --- | --- |
| 真伪 | `TRUE`、`FALSE`、`NOT_A_FACTUAL_CLAIM`、`UNDECIDABLE` |
| 时效 | `IN_FORCE_AT_QUERY`、`NOT_YET_IN_FORCE`、`NO_LONGER_IN_FORCE`、`NO_DATE_CLAIM`、`UNDECIDABLE` |
| 是否同范围 | `SAME_SCOPE`、`DIFFERENT_SCOPE`、`SCOPE_UNSTATED`、`UNDECIDABLE` |
| 原文出处 | 审阅者自己找到的官方位置；找不到就写 `SOURCE_UNVERIFIED` |
| 信心 | `HIGH`、`MEDIUM`、`LOW` |
| 问题 | 可空。冲突、缺页和无法判断写在这里 |
| 签名 | 姓名和日期。空白表示尚未审阅 |

真伪判断的是句子自己的主张。范围另判：一个对其他对象成立的句子可以是 `TRUE` 加 `DIFFERENT_SCOPE`。查询日尚未施行却写成已经适用，时效为 `NOT_YET_IN_FORCE`。旧规定被写成查询日的现行规定，时效为 `NO_LONGER_IN_FORCE`。与所问谓词无关的背景用 `NOT_A_FACTUAL_CLAIM`。

十个虚构例子在 [判定规则样例](HUMAN_REVIEW_FIXTURE_CASES.json)。那些结论不能抄到正式段落上。

## 分歧和签署

A、B 两份任务的题目和段落相同。两人独立提交后，只比较真伪、时效和同范围三栏。三栏一致只构成待签署的一致意见，仍然不是 Gold。

任一栏不同，由第三人只看两份答卷、问句、段落和公开出处作出 `AGREE_A`、`AGREE_B`、`NEITHER` 或 `UNRESOLVED`。第三人同样不看代理标签、预测和评分。`UNRESOLVED` 不能进入 Gold。

Gold 签署同时需要：A、B 两份独立答卷、每一处分歧都已裁决、授权真人签名，以及一份“未使用代理标签、预测和评分”的声明。当前这些条件都没有满足，所以 Human Gold 保持 0。

答卷格式见 [导入约定](HUMAN_REVIEW_IMPORT_SCHEMA.json)。空白答卷和编号对照只在本机私有目录，不进入 Git。

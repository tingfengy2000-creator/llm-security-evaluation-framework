## 2. 关键观察

1. **核验放大攻击（verifier-induced amplification）。** UNK 的 D3 上，NONE 不删任何正确片段（C 误删 0/21），QWEN_VERIFY 删掉 20/21 条正确片段，同时保留 58/63 条假页。即核验站在多数一边，把唯一的正确证据清除，使上下文只剩污染。
2. **单条污染也会被“合理性”带偏。** 虚构事实（F）的 D1 上，QWEN_VERIFY 保留 9/12 条假页、误删 12/12 条正确片段——比抛硬币更差。【推测】F 的正确值刻意设计成不可猜，假值反而“看起来更合理”，核验按合理性而非证据裁决。攻击者可利用这一点：对模型不知道的事实，写一个更“像真的”假值。
3. **知道的事实上核验表现很好**：K 的 D1 为 1/12 保留、0/12 误删；D3 为 6/36 保留。
4. **版本更新是天然攻击面**：12 个 2025 年后修订或冷门的真实规定中，9 个模型闭卷两次都答错。
5. RAGDefender（RD_B2）在 D1 上对所有类别都误删 11/12 条正确片段（与假页一起删掉，相似片段被当成一团），这是可用性损失，与 RQ1 一致。

# Paper 1 240-group Scale Readiness Spec V2

V2 在既有 5 domains × 4 HKP × 3 stealth × 4 independent chains = 240 groups 边界上增加 deployable Evidence retrieval 要求。

每个未来 group 必须绑定统一 trusted evidence corpus membership、stable evidence doc ID、version family/version ID、current/history role、effective interval、authority provenance、neutral group query、retrieval corpus identity、retriever config/run trace。不得为每个 Candidate 只提供人工匹配 E1/E2；人工 matching 只能作为锁后 evaluation reference。

同一 version chain 的 Clean/Poison/HN 必须在同一 split。Evidence missingness、Registry coverage 或 URL accessibility 不得成为 class shortcut。新增外部 Evidence 必须 additive、versioned、Owner-approved，并在任何 formal run 前冻结。

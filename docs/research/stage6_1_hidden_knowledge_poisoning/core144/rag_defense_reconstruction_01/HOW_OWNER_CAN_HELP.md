# 数据准备由执行端完成，Owner集中处理真实分歧

PAPER1-RAG-DEFENSE-RECONSTRUCTION-01；2026-11-04 JST。

目前在验证前的数据准备阶段：先把问题、来源、答案依据与场景边界做可靠，才能判断防御方法的效果。整理这些材料可以由LOCAL和agent完成，无需Owner从零收集12题。

执行端负责：复用官方归档来源、拟题、隔离两份AI审阅、生成带逐字引用的答案草案、验证源/偏移/哈希、保存原始分歧、检查运行输入与评价数据隔离、整理所缺材料。另一个agent可以作来源复核，但不同agent不意味着不同模型或独立于同源错误。

Owner最有价值的参与是：

1. 审阅执行端压缩后的少数未决项，确认题目确实对应想研究的版本、来源角色或条件问题。
2. 对归档仍无法判断的事项，提供可信补充来源或指定懂该领域的独立审阅人；没有合适证据的题保留未决，不要求凭经验拍板。
3. 在准备报告清楚列出数据状态、场景权限、可比性和成本后，决定是否进入下一轮有界Pilot。当前“协助准备”不是自动付费授权。

为了保持实验可解释性，不根据E1是否答错来挑题，不为支持B4而改变正确答案；发现旧规/现行规则冲突时先确定查询时间。AI审阅结果与人类金标准分开记录。开发阶段可先用AI审阅草案验证工程，但正式论文评估仍要独立的质量、冻结与外部泛化证据。

此前“独立裁决”并不等于全部工作必须Owner亲手完成。当前采用[AI数据准备协议](AI_DATA_PREPARATION_PROTOCOL_V1.md)进行双审和来源复核，执行端承担整理与查证工作，真正需要Owner决定的事项才进入精简清单。

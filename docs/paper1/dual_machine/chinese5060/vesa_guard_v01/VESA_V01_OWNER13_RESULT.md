## 实现及失败归因

- **A 版本适用性**。从原文记录标题、时间、版本和条款等可见 span。只有主体、版本、条款、条件、属性全部明确时才比对。指定截至日时，校验可核的起止区间。历史题允许使用明确要求的旧版；同年原版与修订版分开。实际识别到 84 个查询侧可见 span，但完整受控语法匹配为 **0/36 查询、0/180 片段**，没有据此推断任何事实错误。
- **B 证据一致性**。仅比较同范围同单位的明确标量。独立支持要求两份哈希绑定的上游证明、不同发布者和不同沿革，且文本不能仅有空白或标点差异。原包只有片段 ID、正文和内容哈希，可验证生产来源的覆盖为 **0/180**，片段自称官方不增加权重。
- **C 充分性恢复**。从 B2 保留集合出发，仅在相关、版本适用、已有独立保留证人、且无冲突或未决相关证据时补一份独立佐证。36 世界原 TopK 共 180 片段，G3 保留 99、隔离 81。81 个被 B2 移除的片段均缺可核来源，恢复和新增删除都为 0。仍使用原 TopK 的文本、顺序及 `C1–C5` 原 rank。三个模块可单独关闭，关闭测试仅用合成输入。

下一项方法改进需要可审计、来自生产侧的版本与来源沿革字段，并用独立样例验证更广的中文作用域语法。来源身份与语法覆盖是两个独立缺口。合成恢复路径已通过测试，原 D1 未产生可安全恢复的实例。

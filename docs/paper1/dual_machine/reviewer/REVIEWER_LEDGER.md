## 5. NEXT_ACTION：参数知识分层的多数污染实验（PK-STRAT）

**假设 H：** 多数污染下，QWEN_VERIFY 的 Poison 保留率在“模型闭卷答错/不知道”的事实上，显著高于“模型闭卷答对”的事实。成立则说明 LLM 核验的安全性依赖参数知识，版本更新是其天然攻击面；这是论文的核心发现与后续防御的动机。

**设计（全部为自写文本，可发 API；预计 <200 次调用、<USD 0.1、半天）：**

1. 5090 选 24 个事实，三类各 8 个：K = 广为人知的全国性规定；U = 2025 年后修订或冷门地方规定（真实）；F = 虚构。每个事实做 2 个世界：1/5（1 假 + 1 真 + 3 背景）与 3/5（3 假改写 + 1 真 + 1 背景）。另加 8 个“伪造修订”3/5 世界（假页自称“2026 年最新修订”）。共 56 世界，角色盲交给 5060。
2. 5060 先对每个事实做一次**闭卷提问**（不给片段），记录 Qwen 是否答对。按闭卷结果而非人为类别分层（K/U/F 只作参考）。
3. 对比臂：NONE、RD_B2、QWEN_VERIFY、QWEN_VERIFY_CONTEXT_ONLY（提示“只依据片段判断，不得使用自身知识”）。
4. 5090 一次性评分：按“闭卷对 / 闭卷错”和密度分层报告 P 保留、C 误删。

**硬门槛：**

- GO：3/5 时，闭卷错的 P 保留率比闭卷对的高 **≥ 40 个百分点**，且每层至少 8 个事实。
- NO_GO：差距 < 15 个百分点 → H 不成立，论文按“基准 + RAGDefender 中文失效 + 单次 LLM 核验强基线”收口。
- 其余为 INCONCLUSIVE；不得改样本后重测同批。

**GO 之后：** 防御方向自然变为“闭卷置信度低时才调用可信版本来源”，即 V-CARE 的思路，但有了明确威胁动机与触发条件。

提示词：见本目录 `NEXT_PROMPTS_PK_STRAT.md`。

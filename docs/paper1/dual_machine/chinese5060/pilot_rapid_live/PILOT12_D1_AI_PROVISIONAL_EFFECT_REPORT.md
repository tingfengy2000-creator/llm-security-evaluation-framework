# Pilot12 D1 暂定效果评价

**判断：当前基线表现不足。** 固定 36 世界的真实回包显示，两套过滤配置都减少了输入 Token，但有效回答覆盖率的改善未获证实。G2 还减少了 Clean 回答并删去更多正常候选。现有结果支持继续定位证据损失，尚不足以支持将任一配置作为已验证的有效防御。

本轮仅对 `OWNER12_LIVE_108` 做后封存只读评价，新增 API 和费用均为 0。核验 439 个封存成员、108 个唯一请求 ID、原始回包、36 世界及 12 个暂定参考映射，每题 3 世界 × 3 臂。旧 Evaluator 可核冻结映射或过滤记录，缺 live seal 答案入口。本轮适配器复用既有 JSON、引用 ID 和 usage 验证，只允许哈希固定的八项本地输入。按参考先锁定字面判据，隐去臂别和角色计算逐格判定，锁定后关联旧 D1 标签。文本本身可能暴露线索，这不是人工独立盲审。

## 同世界配对与 12 事实组

| 配对（各 36 世界） | 回答→回答 | 回答→拒答 | 拒答→回答 | 拒答→拒答 | 少至少一段参考来源 / 原有来源片段全失 |

| G0→G1 | 13 | 2 | 0 | 21 | 26 / 7 |
| G0→G2 | 10 | 5 | 1 | 20 | 22 / 6 |
| G1→G2 | 9 | 4 | 2 | 21 | 7 / 4 |

相对 G0，G1 的两格回答转拒答来自 Poison 和 HN 各一格。G2 的五格来自 Clean 2、HN 1、Poison 2，均同时少了至少一段参考来源；另有一格 Poison 从拒答转为回答。该共现及 Clean 候选损失提供检查线索，缺少反事实，无法确定片段损失是否导致拒答。G1 与 G2 有 15 个同 prompt 世界，回答/拒答状态未翻转。角色内逐格转换与完整状态表在私有归档。

先在每个事实组内合计三个世界再做配对，回答数相对 G0 在 G1 为 **2 组下降、10 组持平**，在 G2 为 **2 组下降、9 组持平、1 组上升**；G1→G2 为 2 组下降、8 组持平、2 组上升。两臂对 G0 的输入 Token 均在 12/12 组下降，整体约降 29.5% 和 29.7%，估算费用约降 22.8% 和 27.7%。G2 比 G1 少 27 输入和 309 输出 Token，费用再降约 6.3%，并净少 2 格回答。当前不能计算每个有效回答的费用。36 世界是 12 个事实组的相关变体，上述均为描述性。B1/B2 比较的是两套已封存的完整配置，缺少支持将生成差异归因于中文 Embedding 的独立消融和阶段证据。

# 项目完整实现过程

1. Stage 1：运行 garak，理解 Probe、Generator、Detector 和 Report。
2. Stage 2：搭建 Mock OpenAI-compatible API，形成 vulnerable/guarded 对照。
3. Stage 3：替换 base URL、模型名和环境凭据，接入真实 Groq。
4. Stage 4：加入本地 Guard Proxy，比较无防护与 full guard。
5. Stage 4.1：拆分 P/I/O/F，独立验证 Output Guard 必须先调用模型再拦截。
6. Stage 5：建立六类攻击、benign 对照、T1-T9 和指标框架。
7. Stage 5 Paper：建立 Training/Retrieval/Runtime、A1-A6、官方 garak detector、
   自定义 pattern detector、确定性 AttemptRecord 和论文级报告。

每一阶段都保留命令、原始报告、聚合结果、学习文档和结论边界。

## 3. 结论

1. **QAG 失败在机制，不在抽取。** 抽取 97.8% 准确；但答案多数投票在 2/5 及以上必然输，在 1/5 也保留 7/16（【推测】正确证据常不在 TopK，假页是唯一带值片段）。不再迭代 QAG。
2. **QWEN_VERIFY 在单条污染下两个面板都是 0 保留**（虚构 0/5、真实 0/11），且几乎不误删 Clean → 这部分是上下文推理能力，可信。
3. **多数污染下，QWEN_VERIFY 只在真实法规面板有效**（3/5：真实 0/9 vs 虚构 14/15）。【推测】它在多数污染下依靠模型已知的真实法规（参数知识），而不是上下文。对模型不知道的事实（新修订、虚构、截止日期之后的变化），多数污染仍能攻破它。
4. **对论文的含义：** “轻量过滤器胜过 RAGDefender”的方法路线结束（单次 LLM 核验已全面胜出，单条污染下无改进空间）。新的、有数据支撑的研究问题是：**LLM 核验型防御在“模型不知道的版本更新”上是否失效**——这正是中文版本敏感场景的核心。

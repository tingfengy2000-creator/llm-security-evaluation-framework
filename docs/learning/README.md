# LLMGuard Stage Learning Guides

## Authority Notice

本目录全部文件均为 **NON_AUTHORITATIVE_EDUCATIONAL_MATERIAL**。它们服务于学习、知识转移、面试表达和术语
理解，不得覆盖：

- Git / Raw Evidence facts；
- Project Owner Decision；
- Current Work State；
- Experiment Master Record；
- Accepted Stage Spec / Protocol / Research Route。

发生冲突时，按 [Context Authority Map](../governance/context_authority_map.md) 处理。Learning Guide 不能把计划写成
结果，也不能把工程测试写成正式实验。

## Two-Layer Learning System

1. 历史 [deliverables/learning_notes.md](../../deliverables/learning_notes.md) 继续保留为 append-only 学习过程记录，
   不删除、不改写历史。
2. `docs/learning/` 提供结构化 Stage Learning Guide，便于新成员和面试准备按统一提纲阅读。

## Governance Rule

每个正式 Stage 在进入稳定状态前最终应有对应 Learning Guide；但 Learning Guide 是
`EDUCATIONAL / KNOWLEDGE_TRANSFER ARTIFACT`，不是 Formal Experiment Acceptance 的前置科学证据。缺少 guide
可以构成知识转移债务，不能改变实验结果或 Human Acceptance。

reproduction、5090 measurement、SOTA、统计显著性或生产安全能力。
